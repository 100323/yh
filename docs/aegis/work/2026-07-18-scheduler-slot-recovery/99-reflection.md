# Reflection

Goal：修复正常 cron 在重启和错峰队列期间静默漏做，并让管理员在前端看到漏做与恢复。

DeeperCause：否。持久化缺口位于 cron 与内存错峰队列之间，现已由唯一槽位账本覆盖；任务执行 owner 仍是原批次队列，没有新增第二套执行器。

Evidence：数据库、恢复、分页、marker、路由、视图模型、调度集成与全量回归均有直接测试证据。

Risk/Unknown：PM2 高频 SIGINT 的外部触发源仍未定位；本修复降低其造成的漏做影响，但不宣称消除重启根因。已开始的任务不会自动回放，需管理员根据“中断未重放”告警人工判断。

Decision：实现已部署并验证，部署前备份与回滚材料已保留。
