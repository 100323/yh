# Aegis Project Workspace

This directory contains project-local architecture baselines and reviewed design specifications.

- `baseline/` records evidence-based snapshots of the current system.
- `specs/` contains approved designs that are ready to be planned.
- `INDEX.md` lists tracked documents.
- `BASELINE-GOVERNANCE.md` defines how baseline drift is reviewed.

These documents describe and constrain implementation work; they do not replace tests, runtime verification, or user approval.
